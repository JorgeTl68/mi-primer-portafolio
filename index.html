Cómo trabajamos

Nuestro flujo con Git

Los cuatro pasos que seguimos cada vez que guardamos y publicamos un cambio.

  1. 1

    Revisar

    git status

    Vemos qué archivos son nuevos o cambiaron.

  2. 2

    Preparar

    git add .

    Pasamos los cambios al área de preparación.

  3. 3

    Guardar

    git commit -m "mensaje"

    Creamos una versión con un mensaje que explica el cambio.

  4. 4

    Publicar

    git push

    Subimos los commits a GitHub para que todo el equipo los tenga.
