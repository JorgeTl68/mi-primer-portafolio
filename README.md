# Mi primer portafolio

Sitio web personal / portafolio para mostrar nuestros proyectos escolares de la materia **Desarrollo Web Integral**. Está hecho solo con HTML y CSS y su historial de cambios se lleva con Git y GitHub.

## Contenido del sitio

- **Inicio:** presentación del portafolio.
- **Sobre nosotros:** integrantes del equipo.
- **Proyectos:** tarjetas con los trabajos de la materia.
- **Contacto:** enlace a este repositorio.

## Estructura

```
mi-primer-portafolio/
├── index.html   # Estructura y contenido de la página
├── style.css    # Estilos del sitio
└── README.md    # Descripción del proyecto
```

## Cómo verlo

**En línea:** https://jorgetl68.github.io/mi-primer-portafolio/ (publicado con GitHub Pages).

**En tu computadora:**

1. Clona el repositorio:
   ```bash
   git clone https://github.com/JorgeTl68/mi-primer-portafolio.git
   ```
2. Abre `index.html` en tu navegador.
